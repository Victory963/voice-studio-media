# Voice Studio 配音工作台（最终版 v2.2）

用自己克隆的声音给视频配音的工作台：粘贴文案 → 一键生成 → 试听/下载 MP3。拍完视频不用再自己录配音。

基于 GPT-SoVITS 声音克隆引擎，本地运行（Windows），支持中文 / 日本語 / English / 한국어 / 粤语 + 自动识别语言，用一段中文声音样本跨语种合成、保持本人音色。

## 结构

| 路径 | 内容 |
|---|---|
| `studio/studio.py` | 工作台服务（:8899）：分句合成、语速调节、成品拼接 |
| `studio/index.html` | 工作台页面：语言选择、生成进度、试听/下载 |
| `Step1-Install-Engine.bat` | 第一步：下载安装 GPT-SoVITS 官方 Windows 整合包（约 5.74GB，只装一次，curl -f 校验 + 大小校验） |
| `Step2-Open-Studio.bat` | 第二步：拉起引擎 + 工作台并打开浏览器（等引擎真正就绪才打开页面） |
| `engine-config-fix/tts_infer.yaml` | CPU 版引擎配置（无 NVIDIA 显卡的机器用这个覆盖整合包默认配置，否则引擎会因 CUDA 直接退出） |
| `voice/ref_text.txt` | 声音样本的对齐文本（与 ref.wav 配套） |

## 内容校验纪律

每句合成后用 whisper 回转写与原文比对，检查参考句泄漏；内容对不上自动重试一次，仍不过整单拦截、不当成品交付。
校验工具本身异常（缺模块/缺 ffmpeg/模型未下载）与内容不合格严格分开：工具坏了照常交付，但明确标注"未经内容校验"并写明真实原因（v2.2）。

## 本仓库未包含的内容（有意为之）

- **`voice/ref.wav` 声音样本本体未上传**：本仓库是公开仓库，声音样本是可直接用于克隆本人声音的素材，公开等于任何人可下载克隆。使用时把自己的 `ref.wav` 放到 `voice/` 文件夹即可（与 `ref_text.txt` 配套）。如需把样本也存进仓库，请先把仓库改为 Private。
- **`nltk_data/`（约 62MB）未上传**：英文分词所需的标准 NLTK 数据（cmudict / punkt / tagger），非本项目代码，本地完整包里有；Step2 通过 `NLTK_DATA` 环境变量指向它。
- **GPT-SoVITS 引擎本体**：由 Step1 从官方整合包下载，不进仓库。
